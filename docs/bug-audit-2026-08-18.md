# Bug 审查清单（2026-08-18）

对全仓库（Rust 后端 + React 前端）的静态审查结果。基线验证：`cargo test` 17/17 通过，`npx tsc --noEmit` 通过。

## 高危

### H1. 严格模式下全屏遮罩可能永久锁死用户屏幕 ✅ 已修复

- **位置**：`src/pages/EyeCarePopup.tsx`（× 按钮、`completed` 自动确认逻辑）
- **现象**：严格模式倒计时结束后（`completed=true`），× 关闭按钮出现，同时 1500ms 自动 `confirmEyeCare()` 定时器启动。若用户在这 1.5 秒内点 ×：`closeCurrentWindow()` 只关闭 `eyecare` 窗口，不关 `overlay-N` 遮罩；窗口销毁导致自动确认被取消。结果所有显示器的全屏置顶遮罩永久残留、无任何关闭入口，护眼计数也未记录。违背 ADR 0003 的设计意图。
- **修复**：严格模式下 × 按钮改为调用 `confirmEyeCare()`（会计数并关闭所有遮罩），而非仅关闭当前窗口。

### H2. 遮罩窗口在高 DPI 屏幕上尺寸/位置错误 ✅ 已修复

- **位置**：`src-tauri/src/window.rs` `create_overlay_windows()`
- **现象**：`monitor.size()` / `monitor.position()` 返回物理像素，`inner_size()` / `position()` 接受逻辑像素。Retina（scale factor 2）屏幕上遮罩变为 2 倍大小且位置偏移，多屏异 DPI 时覆盖错乱。
- **修复**：尺寸与位置均除以 `monitor.scale_factor()`。

## 中危

### M3. 每个窗口都注册全局事件监听 → 重复通知/重复开窗 ✅ 已修复

- **位置**：`src/App.tsx` `setupListeners()`
- **现象**：`App.tsx` 在所有窗口（main/settings/eyecare/overlay）中都注册 `water-reminder` / `eye-care-reminder` 监听。设置窗口开着时喝水提醒触发会弹两条相同系统通知；护眼提醒触发时多个窗口并发 `open_eye_care_window`，后者因窗口 label 重复失败（未处理的 promise rejection）。
- **修复**：仅在 `main` 窗口注册提醒监听（按 `getCurrentWindow().label` 判断）。

### M4. `window.eval("location.hash=...")` 与页面加载存在竞态 ✅ 已修复

- **位置**：`src-tauri/src/window.rs`（settings/eyecare/overlay 三处）
- **现象**：`build()` 后立即 `eval` 设置 hash，此时 `index.html` 很可能尚未加载完，eval 跑在初始 `about:blank` 上，页面加载完成后 hash 被丢弃，护眼弹窗/遮罩窗口可能渲染成默认路由 `/`（设置页）。dev 模式（Vite 加载慢）更易复现。
- **修复**：hash 直接写入 `WebviewUrl::App("index.html#/eyecare".into())`，删除 eval。

### M5. 托盘左键行为自相矛盾 ✅ 已修复

- **位置**：`src-tauri/src/tray.rs` `setup_tray()`
- **现象**：`show_menu_on_left_click(true)`（左键弹菜单）与 `on_tray_icon_event` 中左键打开设置窗口同时生效，左键会既弹菜单又开设置窗口。
- **修复**：移除 `show_menu_on_left_click(true)`（恢复默认 false），左键打开设置窗口（与 CLAUDE.md 描述一致），右键弹菜单。

### M6. 修改设置不重排计时器 ✅ 已修复

- **位置**：`src-tauri/src/timer.rs` `update_from_settings()`
- **现象**：只更新开关和间隔，不重置 `water_next/eye_next`：间隔改长后下一次提醒仍按旧时刻触发；提醒被禁用一段时间后 `_next` 早已过期，重新启用下一秒立即弹提醒。
- **修复**：间隔变化或开关由关→开时，重置对应 `_next = now + interval`。

### L10. 拔掉显示器后旧遮罩窗口泄漏 ✅ 已修复

- **位置**：`src-tauri/src/timer.rs` `exit_system_pause()`

### L12. 托盘切换开关后设置窗口 UI 不同步 ✅ 已修复

- **位置**：`src-tauri/src/tray.rs` + `src/services/reminder.ts` + `src/pages/SettingsPage.tsx`
- 托盘切换喝水/护眼后新增 `settings-changed` 事件，设置页监听并重新加载设置。
